# hxyfront-62008 烟花燃放脚本编排

源提示词编号：10

面向烟花燃放编排师的整场节目编排工具：节目段落、点火节点、燃放点位平面图、型号清单、安全距离 / 容量冲突提示和整场预演。

## 功能

- **时间轴编排**：段落锚定音乐时间点，节点时间 = 段落点火 + 段内偏移。可直接拖动段落块/节点色条，或用 `m:ss.mmm` 输入。改任意时间后立即重算排队与冲突。
- **点位平面图**：每个点位带安全距离（按场地实际米制换算的安全圈）与同时发数上限，可拖拽布点，顶部显示「峰值并发 / 上限」，播放时实时点火脉冲。
- **容量排队顺延**：同一时刻某点位发数超过上限时，多发按 100ms 步长向后顺延，提示里写明**超在哪个点位、顺延多少、实际点火时间**。
- **冲突提示**：
  - ⛔ 两点位同时点火而实距小于安全距离要求；
  - ⏱ 容量超限顺延；
  - ⏪/⏩ 段落点火与绑定音乐点抢拍/错位；
  - 点火时间早于 0:00 或超出音乐结束。
- **整场节目预览**：按实际点火（含顺延）排序的执行单，支持 ▶ 预演、拖播放头、点音乐点跳转。
- **两位编排师协作**：保存走版本化三方合并（base / 对方版本 / 本地版本）。晚保存时先看到对方新增、删除、改过的字段；双方都改且不一致的字段逐项选择保留谁，再确认保存。同机开两个浏览器标签页（顶栏把编排师改成乙）即为真实双人；也可用「模拟乙改动 / 模拟乙删段」按钮造数据。
- **断网续排**：断网后照常编辑，「离线保存」进入本地 outbox（刷新不丢）；恢复网络后逐条重放合并——无冲突的自动并入，有冲突或引用了被删段落/点位/型号的**接不上的段**进入待处理面板，可逐字段定夺、选择是否把离线段/节点重新接回，或放弃/稍后处理。

## 技术栈

React 19 + Vite 7 + TypeScript（无后端：localStorage 充当服务端版本库，`storage` 事件实现跨标签页实时协作）。

核心逻辑全部是纯函数，位于 `src/core/`：

| 文件 | 职责 |
| --- | --- |
| `schedule.ts` | 容量排队顺延、安全距离/音乐漂移/越界检测 |
| `merge.ts` | 三方字段级合并、对方改动 diff、离线接不上判定 |
| `store.tsx` | 草稿/保存/协作/离线 outbox/待处理队列 |
| `sample.ts` | 自带冲突的样例脚本（含容量超限、安全距离不足、音乐错位） |

## 本地运行

```bash
npm install
npm run dev        # http://localhost:62008
```

测试：

```bash
npm test           # 类型检查 + 排程/合并引擎 26 项 + 离线整链路 9 项 + 整树渲染冒烟
```

## 演示流程

1. 打开页面，样例里已自带：D 点位 4 发超 3 发上限（顺延 0.1s）、C×D 安全距离不足、Chorus 段落错开音乐点 3 秒；
2. 拖动段落块改时间，观察冲突即时变化；把 D 点上限调到 4，或把 D 点拖远，冲突消失；
3. 点「模拟乙改动」→ 再保存 → 查看对方改动摘要与字段冲突选择；
4. 断网 → 改几笔并「离线保存」→「模拟乙删段」→ 恢复网络 → 无冲突提交自动并入，删掉的桥段进入「接不上」面板，勾选接回或放弃。
